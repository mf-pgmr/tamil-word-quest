# Project Rules: Tamil Word Quest

## Emoji Policy
- **No Emojis**: Do not use emojis anywhere in this project.
- This applies to:
  - UI labels, button text, badges, tabs, and headers
  - Quiz and game modes (Speed Challenge, Trainer, Scramble, Listen, Missing Letters, Dialogue Reader)
  - Notifications, toasts, floating effects, and status indicators
  - Audio and media controls
  - Code comments and documentation files (including README.md)
- Instead of emojis, use:
  - Clean typographic text labels (e.g., "Play", "Listen", "Normal", "Streak")
  - Minimal inline SVG icons when an icon is needed
  - Semantic Tailwind CSS styling and color accents
