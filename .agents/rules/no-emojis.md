# No Emojis Rule

Do not use emojis anywhere in this repository:
1. User interfaces, HTML files, button labels, tabs, and navigation items.
2. Game modes, scores, timers, streak messages, and badges.
3. Dialogue reader controls and audio player buttons.
4. Documentation (README.md, comments, etc.).

Always prefer clean typography, clear English/Tamil text labels, or clean SVG icons instead of emoji characters.
